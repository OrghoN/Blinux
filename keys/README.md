# Package signing keys

`blinux-keyring` installs the public key in this directory so pacman on every
Blinux system trusts packages from `[blinux]`. Nothing here is secret.

The key is not generated by any script: the maintainer creates it once and
keeps the private part offline. To set it up:

```sh
gpg --quick-generate-key "Blinux package signing <you@example.org>" ed25519 sign 3y
gpg --quick-add-key <FINGERPRINT> ed25519 sign 1y      # testing subkey for [blinux-testing]
gpg --armor --export <FINGERPRINT> > keys/blinux.asc
echo "<FINGERPRINT>:4:" > keys/blinux-trusted
```

Then add the secrets to the GitHub repository:

- environment `release`: `BLINUX_GPG_KEY` (`gpg --armor --export-secret-keys <FINGERPRINT>`)
  and `BLINUX_GPG_PASSPHRASE`, with a required reviewer
- environment `testing`: `BLINUX_TESTING_GPG_KEY` (`gpg --armor --export-secret-subkeys <SUBKEY>!`)
  and `BLINUX_TESTING_GPG_PASSPHRASE`

`release.yml` refuses to run until `keys/blinux.asc` exists.
